# 로그포트(Roguefort) 한글패치

Steam 게임 **Roguefort** 비공식 한국어 패치입니다.

## 받기
👉 **[최신 버전 받기 (Releases)](https://github.com/magicianaos/Roguefort_AOS_Korean/releases/latest)**

- `Roguefort_KR_Patch_v○○.exe` — 한글패치 런처 (설치·되돌리기·제보하기)
- `Roguefort_KR_Review_v○○.xlsx` — 검수표 (선택)

## 설치
1. Steam을 켜고 게임을 구매한 계정으로 로그인, 게임은 종료
2. 런처 실행 → **[패치 설치하기]**
3. 게임 실행하면 한국어로 표시

되돌리기: 런처의 **원래대로 되돌리기** 또는 Steam "게임 파일 무결성 검사"

## 게임 중 단축키
- **CapsLock** — 영어 원문 ↔ 한국어 전환
- **Ctrl+Alt+K** — 화면에 나온 미번역 영어 복사 (제보용)

## 제보
런처의 **[제보하기]** 에 붙여 넣고 보내기 · 스크린샷은 [디스코드](https://discord.gg/MY9PUNFrv9) · 홈페이지 [kr-aos.win](https://kr-aos.win)
