# 로그포트(Roguefort) 한글패치

Steam 게임 **Roguefort** 비공식 한국어 패치입니다. 현재 버전은 **v2.2.0**(게임 0.35.1 대응)입니다.

## 받기
👉 **[최신 버전 받기 (Releases)](https://github.com/magicianaos/Roguefort_AOS_Korean/releases/latest)**

- `Roguefort_KR_Patch_v(버전).exe` — 한글패치 런처 (설치·되돌리기)
- `Roguefort_KR_Patch_v(버전)_bat.zip` — 런처가 열리지 않을 때 쓰는 대체 설치판

## 설치
1. Steam을 켜고 게임을 구매한 계정으로 로그인, 게임은 종료
2. 런처 실행 → **[패치 설치하기]**
3. 게임 실행하면 한국어로 표시

되돌리기: 런처의 **원래대로 되돌리기** 또는 Steam "게임 파일 무결성 검사"

게임이 업데이트되면 런처에서 **[패치 설치하기]** 를 다시 눌러 주세요.

## 제보
런처 「설정」의 「영어 남음 기록」을 켜고 플레이한 뒤, 게임 안에서 **Ctrl+Alt+J** 로 화면의 한국어 문장 목록을 복사해 알려 주세요. 스크린샷은 [디스코드](https://discord.gg/7PBPCweTbR) · 홈페이지 [kr-aos.win](https://kr-aos.win)

비공식 팬 번역이며 게임의 저작권은 원 개발사에 있습니다. 이 저장소와 배포 파일에는 게임 파일이 들어 있지 않습니다.
